**Frontend Wireframes, Interfaces & User Interaction Design**  
EduWhiteboard (TanStack Start)

Below is a complete, practical outline of the interfaces, textual/ASCII wireframes, and interaction patterns. These are derived directly from the PRD (chat + canvas split, warm educational aesthetic, agentic workflow, progressive generation, scene-level revisions, all challenge solutions).

### 1. Information Architecture & Navigation

**Top-level**
- Dashboard (home / project list)
- Project Workspace (the main application surface – most time spent here)
- Settings
- (Future: Asset Library, Team/School workspace)

**Inside a Project**
- Persistent top bar (project context + quick actions)
- Always-available left Chat panel
- Main area with tabs or resizable panes: **Canvas** | **Storyboard** | **Preview**
- Optional right or bottom Storyboard timeline / scene cards

Navigation is deliberately shallow. Teachers stay inside the Project Workspace for creation, review, and revision.

**Main area variants**
- **Canvas tab**: Live Excalidraw. Agent draws via MCP; teacher can select, move, erase, or add elements. Changes can be pushed back to the storyboard JSON.
- **Storyboard tab**: Vertical or horizontal cards showing every scene (thumbnail, narration snippet, duration, elements list, math blocks, camera notes). Drag to reorder.
- **Preview tab**: Video player with numbered scene markers on the scrubber. Clicking a marker jumps to that scene and focuses chat context on it.

#### E. Video Preview + Export

Large centered player + side panel:

- Timeline with scene markers (clickable, show “Updated” badge after partial regen).
- Side list of scenes with one-click “Revise this scene”.
- Download options: MP4 1080p / 720p, WebM, Audio-only.
- Quick branding controls (logo position, intro/outro).

#### F. Settings

Tabbed interface:
- **Voices & Languages** — provider list, sample playback, quality notes for Oshiwambo, defaults.
- **Branding** — logo upload, position, templates.
- **Models** — Ollama endpoint, preferred model, temperature.
- **Asset Library** — browse, upload, tag, Rough.js preview.
- **Render Defaults** — resolution, quality, local vs remote workers.
- **Appearance** — cream theme, high-contrast, reduced-motion.

### 3. Core User Interaction Patterns

**1. Chat as the primary control surface**  
Everything starts and is refined through natural language. The agent responds with streaming text + actionable progress cards and suggested chips (“Make shorter”, “Translate to Oshiwambo”, “Simplify the calculation in scene 3”).

**2. Hybrid editing**
- Natural language in chat.
- Direct manipulation on the Excalidraw canvas.
- Structured editing of storyboard cards / JSON fields.  
All three stay synchronized via the storyboard JSON source of truth.

**3. Progressive disclosure & feedback**
- Immediate static canvas / storyboard preview after planning.
- Low-fidelity or CSS-animated SVG preview while full render runs.
- Full video only when ready (or on demand).
- Teacher never waits without visible status.

**4. Scene-centric revision loop**
1. Teacher clicks a scene marker on the video timeline or a storyboard card.
2. That scene is highlighted; chat context switches (“Focusing on Scene 3”).
3. Teacher types a command or uses card actions.
4. Agent updates the storyboard live and offers “Apply & Re-render only this scene”.
5. Only the affected scene shows a mini progress indicator; the rest of the video remains cached.
6. When finished, the player jumps to the updated segment with a soft “Updated” indicator.

**5. First-time / Empty experience**
- Dashboard empty state with illustration + example prompt chips.
- New project: large centered chat input with example chips and a faint ghost canvas behind.

**6. Micro-interactions & polish**
- Live “Agent is drawing…” indicator + real-time path appearance on canvas.
- Expandable progress cards showing sub-steps or current narration.
- After partial regen: soft glow or temporary badge on the updated scene marker.
- Keyboard shortcuts: `/` focus chat, number keys jump to scenes, `R` regenerate focused scene, `?` shows shortcut sheet.
- Floating status indicator if the teacher navigates away while a job is running.
